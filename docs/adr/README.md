# ADR Index

This folder contains Architecture Decision Records for the VICA Agentic Career MVP.

## Usage

- Create one ADR per important technical decision.
- Give each ADR a stable number and short slug.
- Write the context, decision, and consequences clearly.
- Keep ADRs additive and historical.
- Never rewrite ADR history just to match the current implementation.
